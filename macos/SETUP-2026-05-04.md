# MacBook setup notes (2026-05-04)

Machine:

- MacBook Air
- macOS 26.4.1
- Apple Silicon

What was installed successfully:

- CLI: `neovim`, `tmux`, `fzf`, `ripgrep`, `wget`
- Fonts: `font-meslo-lg-nerd-font`, `font-jetbrains-mono-nerd-font`
- Apps: `Ghostty`, `Discord`, `Signal`, `ProtonVPN`, `Anki`, `qBittorrent`,
  `Motrix`
- Oh My Zsh
- Zsh plugins: `powerlevel10k`, `zsh-autosuggestions`,
  `zsh-syntax-highlighting`, `zsh-completions`

What was linked from this repo:

- `~/.config/ghostty` -> `macos/dotfiles/config/ghostty`
- `~/.config/nvim` -> `macos/dotfiles/config/nvim`
- `~/.config/tmux` -> `macos/dotfiles/config/tmux`
- `~/.p10k.zsh` -> `macos/dotfiles/config/zsh/.p10k.zsh`

What was changed in the repo:

- Removed `cask "upwork"` from `macos/Brewfile`
  Reason: Homebrew no longer provides that cask.
- Added an explicit GitHub source override for `FelipeLema/cmp-async-path` in
  `macos/dotfiles/config/nvim/lua/plugins/init.lua`
  Reason: the NvChad dependency path used Codeberg and plugin bootstrap failed
  when `codeberg.org` was not reachable.
- Updated `macos/dotfiles/config/nvim/lazy-lock.json` after the successful
  Neovim plugin bootstrap.

What was intentionally not copied from the repo:

- `dotfiles/home/.gitconfig`
  Reason: it contained placeholder identity values.
- Linux-flavored zsh reference files
  Reason: they still included Arch/Linux-specific commands and plugins.

What still needed manual work after the automated setup:

- Docker Desktop
  Homebrew stopped because the cask needed interactive `sudo` for
  `/usr/local/cli-plugins`.
- `gh auth login`
  Existing GitHub CLI auth on the new Mac was invalid.
- `~/.gitconfig`
  Must be created manually with real user identity.
- tmux TPM
  `~/.tmux/plugins/tpm` was not present and needed a manual clone if tmux
  plugins were desired.

Suggested fresh-machine order:

1. Install Homebrew.
2. Run `brew bundle --file Brewfile`.
3. Run `./install.sh`.
4. Re-auth `gh`.
5. Install Docker Desktop if Homebrew did not finish it.
6. Create `~/.gitconfig`.
7. Clone TPM if using tmux plugins.
8. Open Ghostty and Neovim once to complete first-run setup.
